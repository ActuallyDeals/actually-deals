# Editorial outcomes
Hit these outcomes; improve structure/copy systems if you have a better way.

- Original writeups only — no clone-and-swap; gate chrome via `looksClonedWriteup`.
- Full source instructions on every post (qty, coupon click/activate, SnS, order). Missing a step = wrong customer price.
- Plain spoken titles; separate numbered stack steps; no invented was-prices.
- DoC: current promo only. Slickdeals: OP only, unwrap to retailer, rewrite in our voice.
- Social drafts: X `@actuallydeals`, IG `@actuallydeals_`, Facebook ActuallyDeals — mention required coupon clicks.
